常见问题：
1、打开 Claude Desktop 出现以下提示：
Virtual Machine Platform not available Claude's workspace requires the Virtual Machine Platform on Windows. Enable this feature, then restart. 虚拟机平台不可用 Claude工作区需要在Windows上安装虚拟机平台。请启用此功能，然后重新启动。 解决方法：需要在Windows功能安装 Virtual Machine Platform（虚拟机平台）
步骤：
点击任务栏搜索图标：搜索"Windows功能" - 启用或关闭Windows功能 - 勾选Virtual Machine Platform（虚拟机平台） - 确定 - 重启电脑。

2、Claude Desktop 接入第三方模型时提示
Your provider setup needs a fix
Some required fields are missing or malformed. Open Setup to finish configuring it.
Claude Desktop 新版，目前禁止使用第三方模型，只能使用自家模型。
解决方法：
1、使用旧版 Claude Desktop。
2、使用上面介绍的工具cc-desktop-switch，接入第三方模型。
